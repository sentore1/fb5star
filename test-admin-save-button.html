🛠️ Admin "Save Layout Settings" Button Test Guide

⚠️ Before You Start:
  • Make sure your development server is running (npm run dev)
  • Ensure you're logged in as admin
  • Have your browser console open (F12)

📋 Testing Checklist

  • Development server is running on http://localhost:3000
  • Logged into admin dashboard (/admin)
  • Browser console is open (Press F12)
  • Navigated to "Layout" tab in admin
  • Database has site_settings record (run SQL script if unsure)

🔍 Step-by-Step Test

Step 1: Open Admin Dashboard

Navigate to: http://localhost:3000/admin

Step 2: Check Database

Open Supabase and run this query:

SELECT COUNT(*) FROM site_settings;

Result should be 1. If 0, run the fix script.

Step 3: Test the Button

  1. Click on the "Layout" tab
  2. Change any setting (e.g., Product Grid Columns)
  3. Click "Save Layout Settings"
  4. Watch for:
    • Alert popup saying "Settings saved successfully!"
    • OR error message in console/alert

Step 4: Check Console for Errors

Press F12 and look in the Console tab for:

  • No errors = Success! ✅
  • "Save error:" = Database issue ❌
  • "Exception:" = Code error ❌

🐛 Common Issues & Fixes

Issue: "No settings record found"

Fix: Run check-and-fix-site-settings.sql in Supabase

Issue: Button does nothing

Fix: Check browser console for JavaScript errors

Issue: Permission denied

Fix: Check RLS policies on site_settings table

SELECT * FROM pg_policies WHERE tablename = 'site_settings';
